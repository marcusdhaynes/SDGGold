COURSE BUILDER

Import a mastery map

Upload a JSON map, or paste one below. Each concept needs a unique id, a title, a tier (0 = foundation), prerequisites (IDs), and Learn / Reinforce / Test content. Prerequisites determine actual unlocking, not visual placement.

How the tree works

Every node follows Learn → Reinforce → Test. A node becomes mastered only after passing its test. A child of several branches is accessible only when every incoming prerequisite is mastered. The course builder rejects circular paths, missing dependencies, duplicate IDs, and prerequisites positioned at the same or later tier.
